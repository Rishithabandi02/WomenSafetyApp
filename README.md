# HerBeacon 🚨

HerBeacon is a women's safety Android application that helps users send emergency alerts and share their live location with trusted contacts.

## Features

- 🚨 SOS emergency alert
- 📍 Live location tracking
- 📱 Emergency SMS to trusted contacts
- 🤝 Trusted contacts management
- 📳 Shake-to-trigger SOS
- 🗺️ Live location on map
- ⏱️ Automatic tracking timeout

## Tech Stack
- Kotlin
- Jetpack Compose
- MVVM
- Firebase Authentication
- Firebase Realtime Database
- Google Maps
- Fused Location Provider
- Android Foreground Service
- Kotlin Coroutines

## Architecture
The application follows **MVVM + Clean Architecture** principles.
